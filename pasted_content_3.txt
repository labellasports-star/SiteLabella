==================================================
2. TROCAR AS IMAGENS DOS CARDS
==================================================

Atualmente os cards dos produtos possuem um espaço reservado para imagens, porém o modelo visual desse espaço está HORIZONTAL enquanto as imagens reais dos produtos estão em formato VERTICAL.

Isso precisa ser corrigido.

As imagens dos produtos devem ser exibidas no formato VERTICAL.

Portanto:

- alterar a área de imagem dos cards de horizontal para vertical;
- aumentar a altura da área destinada à imagem;
- diminuir a largura proporcionalmente;
- criar uma composição visual semelhante a um catálogo profissional;
- manter todos os cards visualmente alinhados;
- manter a mesma altura total dos cards;
- garantir que todas as imagens tenham o mesmo padrão visual.

A área superior de cada card deve ser pensada para uma fotografia vertical de produto.

==================================================
3. NÃO DISTORCER AS IMAGENS
==================================================

NUNCA esticar, achatar ou deformar as imagens.

Preservar sempre a proporção original das fotos.

Utilizar comportamento equivalente a:

object-fit: contain;

As imagens devem ficar completamente visíveis sempre que possível.

Não cortar partes importantes do uniforme.

Não cortar gola, manga, barra, escudo ou qualquer outra parte importante do produto.

Se houver espaço sobrando nas laterais ou em cima/baixo, utilizar esse espaço de maneira elegante.

==================================================
4. PADRONIZAÇÃO VISUAL
==================================================

Todas as imagens devem aparecer de maneira consistente.

Criar uma área de imagem vertical com:

- proporção consistente;
- alinhamento central;
- espaçamento interno uniforme;
- fundo limpo;
- boa distância entre a imagem e as bordas;
- nenhum efeito exagerado.

O objetivo é que os produtos pareçam estar sendo apresentados em um catálogo profissional.

Não aplicar filtros que alterem as cores reais dos produtos.

Não alterar as cores das imagens.

Não adicionar sombras artificiais pesadas.

Não adicionar elementos gráficos sobre os uniformes.

==================================================

Preservar:

- nome do produto;

9. RESPONSIVIDADE
==================================================

Depois de alterar o formato dos cards para vertical, revisar a responsividade.

Desktop:
- cards bem alinhados;
- imagens verticais;
- boa proporção entre imagem e informações;
- grid organizado.

Tablet:
- manter boa proporção;
- evitar imagens esmagadas;
- manter espaçamento.

Mobile:
- imagem vertical com boa visualização;
- texto legível;
- preço visível;
- botão funcionando;
- cards sem cortes;
- nenhuma deformação das imagens.
